# 电脑版使用指南

[返回 README](../README.md)。电脑版负责一次一轮的手动导出；不需要 Docker，也不会开启定时任务。

## 首次启动

从 [GitHub Releases](https://github.com/LittleSixNine/Pawzz-video-downloader/releases) 下载 macOS 本地导出包，解压到普通程序目录，勿把私人照片、登录数据或录像放进源码目录。Mac 安装 Python 3.10+ 后，双击根目录 `start.command`，或在项目目录执行 `bash start.command`。第一次会联网安装 `requirements.txt` 中固定版本的依赖到私有目录，不修改系统 Python。保持启动窗口开启，网页会自动打开。

网页优先使用本机 8080；占用时自动选择空闲端口。实际地址以启动窗口为准。电脑版管理网页固定只监听 `127.0.0.1`，局域网其他机器不能连接它。自动连接使用一次性随机码，有效期 60 秒；浏览器会立即移除地址片段，持久管理密码只进入当前页面内存。刷新或断开页面后使用管理密码重新连接；首次安装默认 `admin`，已有安装继续使用原密码，设置页支持即时修改。

## 配置一轮导出

在“设备与存储”中：

1. **短信登录**：输入官方 App 的手机号，手动发送并填写验证码。程序不把手机号、验证码或临时凭据写入文件；任务结束后继续保留，退出账号或服务关闭时清除临时登录。也可在“高级”中导入已有会话到内存，原文件由你管理，不会被删除。
2. **保存位置**：默认“影片 / Pawzz Video”。修改时填写完整目录，例如 `~/Movies/Pawzz Video` 或 `/Volumes/MyDisk/Pawzz Video`，点“保存位置”。目录不存在时会创建；改变位置不移动已有录像。代码目录不能作为录像目录。
3. **设备连接**：填写设备的局域网 IPv4、序列号，以及当前电脑与设备互通的局域网 IPv4。网页的 `127.0.0.1` 不是回调地址。Mac 可在系统设置的网络详情里查看 IPv4。
4. **导出范围**：开始日期留空会扫描设备现存全部日期。指定单个原片是高级选项，可用于首次验收；不知道路径时留空。
5. **维护许可**：阅读说明后勾选并保存。首页点击“开始导出”。

导出时电脑应保持唤醒、网络连接稳定。macOS 防火墙若询问 Python 的入站连接，请确认是本工具启动的 Python，再允许设备访问回调 TCP 端口（默认 10003）。不要把回调或管理页面映射到公网。

设置页支持修改管理密码：输入当前密码、新密码和确认密码，保存后立即生效，不必重启。首次安装默认 `admin`，已有安装保留原密码；密码不能为空，不限制长度或大小写。其他已连接页面需用新密码重新连接。

在“存储位置”点击“检查实际写入权限”，程序会创建、读取、删除一个临时文件，不改已有录像。任务运行中不能执行该检查。

## 完成、失败和停止

运行期间可查看已经通过校验的新增段数；这不是总文件数或进度百分比。目录或单段回调超时会在本轮追加重试最多 3 次，每次间隔 5 秒；同一 MQTT 连接保留，重新建立接收端并清理未完成文件。校验失败、空间不足、账号拒绝和主动停止不会按超时重试。整轮完成后不再跑下一轮。到任务页可请求停止，或者在启动窗口按 Control-C 停止整个服务。停止清理可能需要几十秒；关闭网页本身不会停止工作。

如果出现失败，先检查诊断页中的本地准备项。登录状态已准备不代表 token 仍有效；设备回调超时通常需要核对本机 IP、端口占用、防火墙和设备所在网络。修正后再运行会跳过已校验文件，不从头覆盖。约 10 分钟内或正在写入的录像会留到下次处理。

一次只运行一个电脑版实例，同一数据目录的重复启动会被拒绝。不要同时让电脑和 NAS 控制同一设备 / 账号。

## 私有文件与命令行入口

Mac 默认位置：

| 文件 | 位置 |
|---|---|
| 管理密码、设置与历史 | `~/Library/Application Support/Pawzz Video/` |
| 启动器创建的 Python 环境 | 同目录下的 `venv/` |
| 原片与校验记录 | `~/Movies/Pawzz Video/`，或网页保存的自定义位置 |

不要把这些目录加入版本控制。备份配置时按凭据管理；删除项目代码不会删除这些私有文件。

已准备 Python 环境的开发者也可执行：

```sh
.venv/bin/python src/local_app.py
.venv/bin/python src/local_app.py --port 8082 --no-browser
.venv/bin/python src/local_app.py --data-dir "$HOME/pawzz-data" --output-dir "$HOME/pawzz-videos"
```

`--data-dir` 选择一套独立私有设置；`--output-dir` 保存新的录像位置；`--no-browser` 只启动服务，通过管理密码手动连接。不要把数据目录设置在项目代码内。Mac 是目前验证的电脑平台；Linux 原生入口可作开发用途，Windows 暂未适配。

## 更新与回退

1. 等待导出结束，在启动窗口按 Control-C 关闭旧程序，不同时启动两个实例。
2. 保留旧程序包，将新版解压到另一个程序目录；不要删除 `~/Library/Application Support/Pawzz Video/` 或录像目录。更新前妥善备份私有配置。
3. 双击新版 `start.command`。它复用原来的私有配置与 Python 环境；依赖版本不匹配时会更新依赖。设备设置、管理密码、历史和保存位置保留。
4. 电脑版登录仅在内存中使用，服务关闭后需重新短信登录；不会因更换程序而自动删除录像。
5. 检查目录、设备设置和许可，再开始下一轮导出。

新版兼容旧管理密码；网页修改后管理密码文件以 JSON 保存，回退旧程序前恢复更新前的 `admin-token` 备份。可选无损修复需要本机 FFmpeg（如使用 Homebrew 可安装 `ffmpeg`）；关闭该选项无需 FFmpeg。

本包是 Python 启动包，不是独立签名的 macOS App，不包含 Python 或用户会话。macOS 是当前电脑入口的目标平台，Windows 尚未适配。本地检查通过不能替代特定设备与固件的实际导出验收。
